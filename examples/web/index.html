texish, rendered in the browser

Each block below is a texish source. The page calls texish.autoRender(), which finds every element with class texish, lays its text out with the pure-Scala SVG backend, and replaces it with the rendered SVG. Glyphs — text and math alike — are filled as vector outlines from the fonts embedded in the bundle; nothing is downloaded separately and there is no server.
